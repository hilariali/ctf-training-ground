# CTF Training Ground

A Capture the Flag (CTF) practice website for secondary school students (Junior: Grades 7–9, Senior: Grades 10–12) preparing for competitions such as the HKCERT Capture the Flag Challenge, the CUHK Cybersecurity CTF Competition, and the International Cybersecurity Olympiad.

## What's inside

- **26 hands-on challenges** across all 7 CTF categories — Crypto, Web, Forensics, Reverse Engineering, Pwn, OSINT and Misc — each with a story, 3-level hints and instant flag checking (Junior 1,700 pts / Senior 3,200 pts)
- **Learn section** — what CTF is, the 7 categories, competition strategy, team roles and ethics
- **Toolkit** — 8 working in-browser tools (Base64, Hex, Binary, URL, Caesar/ROT13, Atbash, Vigenère, Morse)
- **Watch** — short video tutorials for every category
- **Teacher mode** — reveals solutions for classroom use; progress saves per device in the browser

## Use it

Just open `index.html` in a browser — the site is a single self-contained file, no server or install needed. On GitHub Pages it is served directly from this repository.
