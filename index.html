Learn: what is CTF?

CTF = Capture The Flag. In the most common format, called jeopardy style, your team gets a board of challenges grouped by category. Each challenge hides a secret string called a flag. Find it, submit it, score points. More points = higher rank. Simple idea, endless puzzles.

1 · Pick a challenge

Start with low-point challenges — they're the easiest. Read the title and description slowly: they almost always hint at the method.

2 · Hunt the flag

Decode, inspect, dig. Use the Toolkit, search the page source, examine files. Every challenge here is solved with the tools on this site.

3 · Submit the flag

Flags look like this: flag{some_secret_text}. Type it exactly — spelling, underscores and the closing } all matter.

The 7 challenge categories

Every CTF uses roughly the same categories. Here's what each one is, the skills behind it, and your very first step.

Crypto

🔐 Cryptography

What it is: Messages scrambled with ciphers or maths. You unscramble them.

Skills: Caesar, ROT13, Atbash, Vigenère, Base64, hex, hashes (MD5), and spotting patterns.

First steps: Do Junior J3–J4 and Senior S1, then live in the Toolkit's crypto tools.

Web

🌐 Web Exploitation

What it is: Websites hide secrets in their code, cookies and configuration files.

Skills: HTML, browser devtools (View Source, cookies, network), robots.txt, URLs.

First steps: Junior J2, then Senior S3 (cookies) and S4 (robots.txt).

Forensics

🔍 Forensics

What it is: Digital detective work — hidden data inside files, photos and logs.

Skills: File metadata (EXIF), hidden text, file types, strings inside files.

First steps: Junior J5 (hidden text) and J9 (packet capture), then Senior S5 (metadata) + S9 (hex dump).

Reverse

↩️ Reverse Engineering

What it is: Taking a program apart to see how it works and what secret it checks for.

Skills: Reading code, strings, logic puzzles, basic assembly ideas.

First steps: Junior J13 (reverse a string) and Senior S6 (strings) + S10 (XOR), then HKCERT Workshop 2 (24 Oct) covers this properly.

Pwn

💥 Pwn / Binary Exploitation

What it is: Finding bugs in programs (like memory overflows) and using them to take control — inside the competition's own sandbox only.

Skills: C programming, memory layout, Linux terminal.

First steps: The Practice page has three safe simulations — S11 Overflow 101, S12 Integer Wrap, S13 Canary Hunt. Then learn some Linux (OverTheWire Bandit, see Next Steps) and Workshop 2.

OSINT

🛰️ OSINT

What it is: Open-Source Intelligence — answering questions using only public information: profiles, maps, public posts.

Skills: Careful reading, searching, connecting small clues.

First steps: Junior J7, J10 (Geo Hunt) and J11 (Username Hunter) — all fictional profiles and posts.

Misc

🧩 Misc

What it is: Everything else! Encodings, Morse code, binary, QR codes, logic and lateral thinking.

Skills: Curiosity + the Toolkit. If text looks like 0110…, 4a6f… or SGVsbG8=, it's probably an encoding.

First steps: Junior J6 (binary), J8 (Morse) and J12 (nested zips).

Scoring

🏆 How scoring works

Easy challenges ≈ 50–150 pts, medium ≈ 200–250, hard ≈ 300+. In many events, a challenge's value drops as more teams solve it — so solving early easy flags beats one heroic hard solve.

Stuck for 20 minutes? Switch challenges. Fresh eyes win CTFs.

Strategy: how good teams play

🎯 During the competition

  • Easy first. Sweep all the 50–100 pt challenges before touching hard ones.
  • Read everything. Titles, descriptions, file names and even typos are hints.
  • Recognise encodings on sight: = at the end → Base64; only 0–9a–f → hex; only 0/1 → binary; gibberish English → Caesar/ROT13.
  • Write down what you tried so teammates don't repeat dead ends.
  • Use the hints system if the event has one — a hint costs less than an hour of being stuck.

👥 Team roles

  • Crypto person — ciphers, encodings, hashes.
  • Web person — devtools, source, cookies.
  • Forensics person — files, metadata, hidden data.
  • Wildcard / researcher — reads write-ups, tries Misc + OSINT, keeps the team notes.
  • Swap roles between events — all-rounders are made, not born.

⚖️ ETHICS & RULES — read this before you touch anything

  • Only practise on systems you own, or that explicitly invite it — this site, picoCTF, and the other platforms listed in Next Steps are built for practising.
  • Never attack, scan or "test" real websites, your school network, classmates' accounts, or any system without written permission. That's illegal in Hong Kong (Computer Crimes Ordinance) — even "just looking".
  • No sharing flags, answers or accounts during a live competition, and no attacking the scoreboard or other teams outside the official attack–defence rules.
  • CTF skills are defensive skills: you learn how attacks work so you can protect systems. Be the shield, not the problem. 🛡️

The Toolkit

Eight decoders that run entirely in your browser — nothing you type leaves this page. In a real CTF you'd use sites like CyberChef; these cover the classics you'll meet first. Found a suspicious string in a challenge? Paste it here.

Base64 Encode / Decode

Base64 turns text into letters, digits, + / and = padding. If a string ends in = and looks like capital-letter soup, try this first.

Hex Encode / Decode

Hex (base 16) writes each character as two digits from 0–9 and a–f. 66 6c 61 67 is hiding something friendly…

Binary Encode / Decode

Computers store every character as 8 bits. Groups of eight 0s and 1s usually decode to ASCII text.

URL Encode / Decode

URLs can't contain spaces or symbols like = and {, so browsers replace them with %XX codes. CTFs love hiding one encoding inside another.

Caesar Cipher + ROT13

Atbash Cipher

One of the oldest ciphers: A↔Z, B↔Y, C↔X… the alphabet flipped. Encoding and decoding are the same button.

Vigenère Cipher

A keyword cipher: each letter shifts by the next letter of the key (K = shift 10, E = shift 4…). Much harder to crack than Caesar — unless you know the key. Non-letters (spaces, {, _) pass through unchanged and don't use up key letters.

Morse Code Translator

Dots and dashes. Separate letters with a space and words with / when decoding. ... --- ... is the most famous signal of all.
